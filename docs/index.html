Tourbillon

Open-source AI agent orchestration, local-first

Mastra + LM Studio + Next.js

Tourbillon (French, /tuʁ.bi.jɔ̃/ ['toor-bee-yon']) — literally whirlwind or vortex; from the Old French torb(i)illon, rooted in Latin turbo (a spinning top, a whirlwind).

In horology, the tourbillon is the most complex escapement ever invented: a self-correcting rotating cage that counteracts the pull of gravity on the movement's gears, keeping time with relentless precision.

The name fits here — a team of agents spinning continuously through work, self-correcting as they go, driven by an inner heartbeat that never stops ticking.

What It Does

A control plane for running teams of AI agents as a company:

  • Org chart — agents with roles, reporting lines, and hierarchies
  • Work system — goals → projects → issues, with atomic checkout and state machine
  • Heartbeat loop — agents wake on schedule or events, check their inbox, do work, exit
  • Skills — SKILL.md files injected into agent system prompts at wake time
  • Budget tracking — per-agent token budgets with hard ceilings
  • Governance — approval queues with human-in-the-loop gates
  • MCP tools — agents call the control plane API as tools

Built With

  • Mastra.ai — TypeScript agent orchestration (agents, workflows, memory, MCP, Schedules)
  • LM Studio — local OpenAI-compatible API running open-source HuggingFace models
  • Next.js 14 App Router + shadcn/ui + Tailwind CSS
  • Drizzle ORM + PostgreSQL + pgvector
  • WakeRunner + Mastra Schedules — timer/assignment/approval wakes
  • Better Auth — API key + session auth

Get Started

Clone the repository and run locally with LM Studio:

git clone https://github.com/dcolley/tourbillon
cd tourbillon
pnpm install
cp .env.example .env
docker compose up -d postgres redis
pnpm db:migrate
pnpm dev

Open http://localhost:3000
